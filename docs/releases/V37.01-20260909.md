# C2000MAX V37.01 正式版更新日志

发布日期：2026-09-09

适用设备：NRadio C2000-MAX，TF 卡运行 ImmortalWrt

系统：ImmortalWrt 25.12-SNAPSHOT by inst. / Linux 6.12.94

LuCI：c2000max-v37.01 branch 26.248.12024~e9cdc0a

本版汇总 v36.5 之后的网络修复及近期 37.01 测试版、APP 和测速热修复，移除用户界面的 LAB 版本标记。“正式版”为本次发布编号，不代表下文列出的驱动兼容性、吞吐和长稳限制已经解决。

## 主要更新

### 鲲鹏 APP 支持与灯光联动

- 集成 APP 支持后端 **1.11.0-r2**、LuCI 设置页 **1.5.0-r10**；兼容此次提供的新版鲲鹏 APP（APK 文件名 3.2.0，内部版本 3.2.1），保留旧版 DES/AES 协议兼容路径。
- 补齐新版设备详情、网络状态、CPU/内存及仪表盘速率所需字段。对接实际接口累计收发字节，改进缓存更新、状态上报和数据时效，设置页可调整相关刷新周期；不宣称本轮修复了逐客户端速率统计。
- 适配本地/远程灯光查询、开关及定时关闭，支持跨午夜时段；联动系统中可控制的 Linux LED 类指示灯。
- 修复桥接服务退出后的所属子进程清理，避免重复进程、后台查询和资源残留。
- 不通过清空设备密码或绕过鉴权来兼容新 APP；原有用户配置予以保留。本轮构建前，用户已确认新版 APP 本地和远程均可显示数据。

### 内网测速

- 集成测速后端 **1.2.0-r1**，前端管理包 **1.1.0-r1**。
- 下载流停滞时进行有上限的重连恢复；仍有有效连接时不因单条流超时立即判定整轮失败，同时保留异常提示。
- 上传改为服务端固定采样窗口，按实际接收字节与采样时间计算，排除预热和结束确认等待时间，修正原先上传统计偏差。
- 使用共享上传数据块，限制上传并发，为控制请求预留连接；补充会话归属、超时和取消清理，减少请求挂起。
- 测速服务单独使用 CUBIC，不修改全系统 TCP 策略，不更改 HNAT 或限速插件配置。不添加“跑满”补偿系数。
- 该插件测的是终端到路由器本机服务的应用层吞吐，不等于交换/路由转发上限，也不等于无线协商速率。

### 网口与网络加速稳定性

- 提前在启动阶段加载专用 2.5G PHY 驱动，避免网口先被通用 PHY 接管后出现自动协商异常。
- 增加以太网 debugfs 的 MAC、统计及 PCS 空对象保护，避免缺失硬件实例时访问空指针。
- 修复 HNAT WDMA 端口映射查询生命周期和 WARP 回调边界，处理前期测试版启动循环相关路径。
- 纳入 WHNAT 原子上下文分配、QDMA 队列范围及非 IP 二层报文分类修正。
- 保留限速插件优先级和 NR QoS 冲突保护。WAN、5G+WAN 模式仍采用软件流量卸载回退；本版不宣称这两种模式已实现可靠 HNAT。

### 5G NR 启动与拨号

- SIM/模组供电服务前移至 S09，允许与其他系统启动任务并行。
- SIM 恢复等待 AT 查询队列，并为 QModem 增加有界拨号门控，减少 SIM 切换、CFUN 操作和拨号抢占。
- 修正 BusyBox 字符类支持相关的 MT5700 模组识别问题，以及 CGPADDR 的 CID/完整地址字段解析。
- 加强停机与拨号门控进程生命周期检查，避免关闭后再次触发供电或残留操作。
- 增加启动时序观测能力；不同 SIM、信号和运营商条件下的联网时长仍需实机冷启动验证。

### Wi-Fi 驱动与 MLO

- 集成 Deco GPL `765c6bef` 主驱动及同源 HWIFI，搭配 WARP `20250919-9c1cfa`、OSAL `a53418`；WM/ROM 使用固定 mt76 来源提交 `be5ce7910521492d4a2e4ce7ee3843680a46c047` 中的 MT7993 2026-03-10 未修改配对文件。
- 这是当前可获得源码与固件的组合适配，不是已经取得完整 `39602c` SDK，也不是把厂商驱动替换成 mac80211。
- 加强 TTLM/NT2LM 长度、帧类型、当前 IE 分发和状态更新顺序检查；完善 PN/STA 信息的 WCID、BSS 和返回值校验。
- 修正 OSAL netdev 引用生命周期和错误传播；保持主驱动与 HWIFI 两份构建源码的对应补丁一致。
- 保留 MLO 管理及默认禁用预设、普通 SSID/MLO 模式保护。错误状态不伪装成正常速率。

## 镜像使用与官方系统保护

- `*-sdcard.img.gz`：压缩 TF 卡整卡镜像，可解压为 IMG 后写入 TF 卡；同时提供未压缩 IMG。
- `*-sysupgrade.bin`：仅用于具备本项目 TF 升级流程的 C2000MAX ImmortalWrt。不要当成官方系统固件、通用 U-Boot 包或 SPI-NOR 全盘镜像使用。
- IMG 采用实际 SquashFS 大小加初始 **64 MiB** 可写层的紧凑布局，首启扩容脚本会根据 TF 卡空间扩展；不分发整张大容量 TF 卡的空白空间。
- 组装时仅保留参考 TF 镜像的引导/校准分区，内核及根文件系统全部替换为本次产物，可写层为新建零数据，不复制旧 overlay 或旧用户设置。
- 保留 SPI-NOR 分区只读保护；“重启到官方系统一次”路径继续禁用，不提供写官方 Flash 的操作。
- 本次只在本地编译、验证和打包，未连接设备安装、刷写或修改官方系统。
- **本次不提供 ITB 升级包**：当前验证的是 TF IMG 与项目专用 sysupgrade BIN 流程，不能把 FIT/ITB 改后缀视为兼容升级包。
- 升级前备份配置；跨多个测试版且出现遗留配置问题时，应先保留备份，再决定是否全新写卡。首次设置后建议为管理界面配置密码。

## 已知限制

1. **2.4G 开放无加密下部分客户端仍只能协商 Wi-Fi 6。** 之前同设备 A/B 中开放网络使用 HE，OWE 使用 EHT；本版为老设备兼容保留开放 2.4G，未把该问题标记为已解决。
2. MCU 完整 ABI、MLO/普通 SSID 共存、不同客户端和长期高负载稳定性仍未全部验证。驱动和固件配对文件通过哈希及离线检查，不等于所有运行路径均已验证。
3. 部分网卡/链路的大流量重传或停滞根因尚未完全确定。测速逻辑修复不保证每台设备都能达到 2.5G 有效吞吐，也不能替代对网口、网线、网卡驱动和射频条件的排查。
4. 新版鲲鹏 APP 切换 Wi-Fi/手机流量时可能缓存“本地连接”状态；如远程空白，请完全结束 APP 后通过手机流量重新打开，用户已验证此方法有效。
5. APP 的本地速率页面仍有客户端固定时间分母与实际刷新间隔不一致的限制，不能把它视为精密测速工具；不在服务端乘系数掩盖。
6. 灯光控制仅覆盖系统可安全控制的 Linux LED 类指示灯，不承诺关闭 PHY 内部等未暴露控制接口的灯，不写未验证的寄存器。
7. 既有设备 Lua 对超过 32 位的十六进制数转换存在限制，部分较大的 Cell ID 等数值仍需后续处理；未宣称所有模组字段均已修复。
8. 缺少配套 TESTMODE 运行固件，**不支持射频测试模式，请勿开启 `TestModeEn`**，否则可能导致驱动加载失败。
