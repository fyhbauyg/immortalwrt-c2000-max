# C2000MAX V37.5 Beta

本地更新日期：2026-09-27，沿用原 V37.5 Beta 文件名并覆盖。基于当前 V37.01 工作树及已有修复，系统为 ImmortalWrt 25.12-SNAPSHOT，内核 6.12.94。

## 镜像

- `C2000MAX-V37.5-Beta-20260926-sdcard.img`：写入 TF/SD 卡的完整镜像。
- `C2000MAX-V37.5-Beta-20260926-sdcard.img.gz`：同一 SD 镜像的压缩文件。
- `C2000MAX-V37.5-Beta-20260926-sysupgrade.bin`：供现有 C2000MAX TF 卡系统通过 LuCI 固件升级使用。
- `SHA256SUMS`：以上三个文件的 SHA-256 校验值。

SD 镜像保留原参考镜像的启动链和校准分区，替换内核及根文件系统，初始可写区域为全新 64MiB，首次启动沿用现有 TF 扩容逻辑。BIN 使用 TF 系统专用升级路径。生成镜像后没有对路由器刷写或执行重启。

## 本版变化

1.0.10：移除首页设备数量后的说明和资源卡提示；筛选输入行随列表滚动，不再悬浮覆盖；使用本地 Lucide 图标及许可证；品牌改为 NRadio C2000-788。内置用户提供的 C2000-788 图片，电脑双击、手机双击或键盘 Enter/空格切换，选择保存在当前浏览器。

tcpdump 4.99.6-r2 与固件 libpcap 1.10.6 一起本地构建，修复软件源二进制要求远程捕获符号而固件库未提供的问题。真机帮助信息、网卡枚举及抓包通过。

雷神更换为官方新版通用 OpenWrt 引擎 1.2.2.52（包版本按集成日期 2026.09.27），使用 iptables 兼容后端和 TUN。更新启动参数、INI 配置、设备类型迁移和 LuCI 状态读取；保留启用开关，镜像默认关闭。未安装厂商自动升级监控器。旧账号绑定可能需要在 APP 重新连接，实际线路与套餐由官方 APP 管理。

1.0.8：补全 LTE RSRP、B 频段与载波数量，SINR 未上报时使用 RSRQ；在线数量按关联与 LAN REACHABLE 的 MAC 去重，排除 STALE 和上行邻居（有线离线受邻居状态老化延迟影响）。轮播每 3 秒切换，修复管理员悬停、深色等待弹窗、手机下拉筛选与边界；手机页脚精简，抽屉文案改为 ImmortalWrt 控制台。

手机滑动修复：横向表格仅限制横向滚动传递，纵向手势可以滚动整页；QModem 信息卡片排序限于鼠标拖动标题，触屏保留滑动和点击折叠。已通过 412×915 触屏纵向/横向滑动、折叠与桌面拖动排序回归。

本次补丁修复启动优先级下拉框和保存按钮始终被禁用的问题：改用 DOM 的 disabled 属性，避免 LuCI 将 false 序列化成仍会生效的 HTML 布尔属性。浏览器回归覆盖实际选择、点击保存，以及不可读取时保持禁用。

1. 默认使用 C2000MAX UI 1.0.10-r1，包括保留配置升级。包含此前确认的紧凑控件、接口按钮排列、浅深色主题、登录毛玻璃效果及品牌文字修改。
2. 首页按系统 `MemAvailable` 显示可用内存和占用率，保留物理分配色条，避免把可回收缓存全部当作不可用内存。
3. 以“系统 → 重启 → 启动优先级”替代一次性官方启动。可保存 SD/TF 优先或 Flash 官方系统优先，分别写入 `boot_from_sd=1/0`，在后续重启持续生效。保存与立即重启分开。
4. 仅独立 `u-boot-env` 区域可写；Factory、bdinfo、FIP 和 factory-overlay 仍只读。首次写入前备份完整 64KiB 环境到 `/etc/c2000max/u-boot-env-before-priority-change.bin`，并纳入保留配置升级。检查板型、NOR 类型、唯一分区、实际偏移、擦除粒度和环境 CRC；拒绝覆盖未知自定义命令，保存后回读确认其他变量没有变化，相同设置不重复写 Flash。
5. LuCI 版本标识更新为 `c2000max-v37.5-beta branch`；完整构建标识保存在 `/etc/c2000max-build`。
6. 删除 `/cgi-bin/luci/admin/status/cpe` 菜单路由及其独立页面，保留新的 C2000MAX 首页。
7. 登录页内置 2026-09-26 中国区必应壁纸，首次启动和无外网时直接显示。后台下载失败每 30 秒重试，成功后恢复 15 分钟检查间隔；登录页每分钟检查新壁纸，成功预加载才切换，失败保留当前背景，输入中的密码不会被刷新。
8. 首页 RAM、RootFS、SWAP 进度条收到数据后平滑填充，后续刷新平滑变化，动画约 650ms；系统启用“减少动态效果”时立即显示数值。

选择 Flash 优先后，不会自动回到 TF 系统。需要回到 TF 时，请在官方系统的启动设置里改回 SD 优先。保存优先级会清理旧版已知的一次性启动标记；未知自定义启动命令不会被覆盖。原一次性接口已撤下，旧命令保留为不可写的退役提示。

内置壁纸为“熊耳国家纪念区附近的雪松台地和骡子角”，保留 Bing 返回的摄影署名。Bing 元数据使用 `202609251600` UTC 起始时间，对应北京时间 2026-09-26。图片来源和署名随固件 `wallpaper/default.json` 保存。

## 内存检查

本次在运行设备上清理了七个已经安装的主题临时 APK，`/tmp` 占用减少约 **21MiB**。复查可用内存约 **148–156MiB / 480MiB**，主要用户进程 RSS 均低于约 9MiB，zram 没有交换负载，内核日志未发现 OOM。

内核不可回收 slab 约 66MiB，短时采样稳定。当前内核没有完整 slab 对象统计和 PSS，短时检查不能排除长期泄漏。没有为了降低数字而停止网络、统计或 APP 服务。现有 conntrack 上限、按需代理服务和 daed 资源回收继续保留。

清理临时文件带来的节省已发生在当前设备；新镜像本身不含这些临时 APK。内存显示口径修正不代表同等数量的物理内存被释放。

### SRM825 AT adaptation (2026-09-29)

- Accept documented EN-DC and quoted CELLINFO modes; always query serving cells with mode 1 independently of PDP index. Correct NSA PCI/field bounds and mark LTE/NR records for dashboard consumers.
- Add MeiG SIM active-slot parsing and capability detection. Board SIM switching verifies the selected channel and restores the prior GPIO/channel when a command acknowledges but does not switch. Requires modem firmware with dual-SIM support; physical SRM825 validation remains pending.
- Prefer valid NR RSRP for NSA signal LEDs, with LTE fallback. Reload QModem configuration on overview entry and accept override AT ports. The reported overview failure still needs fresh affected-device diagnostics to confirm its cause.
- Synthetic AT fixtures and board SIM rollback/LED schedule regression tests pass. No SRM825 AT writes were performed on the local MT5700 router.

### SRM825 cold-start follow-up (2026-09-29)

- Normalize prefixed, bare and echoed MeiG identity responses, including +CGMM: SRM825.
- Re-probe remembered modem devices on startup, including late USB enumeration and persisted disabled state. Do not delete network configuration when the device path is temporarily absent. Existing scanner retry limits are retained.
- Interactive AT RPC requests wait at most three seconds per serialization lock, report queue-busy errors, and release only locks actually acquired. This does not reset a hung modem or establish the cause of the reported timeout.
- Identity/startup/lock ownership fixtures pass. Remote SRM825 cold-boot hardware confirmation is pending because no post-failure logs were available.

### SRM825 冷启动端口事务与信号灯修复（2026-09-29）

故障日志确认探测 ttyUSB2 后 SIM 恢复重新选择 ttyUSB1，造成事务重复申请全局 AT 锁。现在整个 SIM 事务固定端口，跨端口调用立即失败；后台排队默认最多 10 秒/锁，LED 查询最多 1 秒/锁。保留正常信号阈值及未知信号提示。加入冷启动锁回归和 LTE/NR LED 模拟测试。用户设备断电两分钟实测待完成。

### 信号灯及 SIM 复用器后续修正（2026-09-30，尚未重新打包整机镜像）

信号灯优先读取 45 秒以内有效小区缓存，支持带 dBm 单位、空白和 Unicode 负号的数值；无效/过期数据继续查询。Fibocom 通道无法识别时拒绝改 GPIO，避免把 FM350 命令语义直接套到 FM150。GPIO 调试按钮改为电平名称，明确不代表实际换卡。FM150 冷启动故障和 SRM825 持续闪绿仍需当前设备诊断验证。
