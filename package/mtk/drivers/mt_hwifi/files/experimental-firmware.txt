The binaries are only installed under names requested by the vendor loader;
their contents are unchanged. No older TESTMODE, CASAN or idxlog firmware is mixed in.

Chip ID, executable download container and entry match the expected loader.
Runtime MCU commands, ordinary EHT, MLO, WED/RRO and HNAT are NOT verified.
Even a single-link EHT AP uses some MLD paths: MLO disabled is not an ABI guard.
Compilation and image verification do NOT prove working Wi-Fi or safe RF behavior.
Test only with a separate TF card and wired management; retain a known-good card.
Do not write bootloader, firmware, environment or factory partitions in official SPI.
The existing C2000MAX SPI read-only and factory-calibration fail-closed guards remain.

MLO is configured but defaults off. This build does not silently remove MLO support.
TESTMODE executable is unavailable; RF test/calibration mode is unsupported.
The existing test-mode startup helper can select TESTMODE if the factory test
flag is set (factory offset 0x1af bit 0) or a user enables TestModeEn. In that
case firmware loading may fail. This build does not clear factory flags or
silently substitute a different executable. Restore a known-good TF card.
Inherited DFS debugging settings are test-only. Do not use as a production AP.
