# C2000 UI 设计规范 v1.2

适用于 C2000MAX LuCI 主题 1.0.2 和组件展示页。以紧凑、清晰的设置界面为默认密度；首页保留设备正视图和状态卡片。

## 尺寸与密度

| 项目 | 桌面 / 平板鼠标操作 | 手机 ≤700px / 触屏 |
| --- | --- | --- |
| 输入、下拉框、按钮 | 32px 高，14px 字号 | 40px 高，14px 字号 |
| 勾选框、单选框 | 16px 图形，32px 行内命中区 | 16px 图形，40px 行内命中区 |
| 表单行上下内边距 | 各 8px | 各 10px |
| 标签 / 说明 | 14px / 12px | 14px / 12px |
| 标签和字段间距 | 16px，两列 | 4px，单列 |
| 主卡片内边距 | 16px | 14px |
| 嵌套面板内边距 | 12px | 10px |
| 表格单元格 | 8px × 10px | 同左，表内横向滚动 |
| 输入 / 按钮圆角 | 6px | 6px |
| 面板 / 卡片圆角 | 10px / 16px | 同左 |
| 顶栏刷新 / 外观容器 | 同为 40px 高 | 刷新 40px，外观展开选项 40px |

登录输入和提交按钮保持 48px；侧边栏与底部导航保持原有点击范围。既有桌面首页 90% 显示比例保留，设置页面通过上述尺寸规则控制密度。

LuCI 的 `.hidden` 和 `CBI.HiddenValue` 优先于布局规则，隐藏字段不占位；只含隐藏字段的分组不绘制空卡片。字段行清除上游额外的 18px 底部外边距。

不要以每层再加一张大卡片组织表单。无线弹窗最外层 Section 不加边框或内边距，设备与接口分组各保留一层浅底面板。弹窗最大高度限制在视口内，滚动条使用细轨道并裁切在四角 16px 圆角内。

表头保持横向文字，运行时间整项不折行；信号、速率与地址列设最小宽度，窄屏在表格内部滚动。无线和 MLO 概览行不使用整行 hover 高亮，保留按钮反馈。

## 样式职责与加载顺序

1. `tokens.css`：颜色、字号、圆角和密度变量。
2. `components.css`：可复用组件；`styles.css`：页面外壳；`c2000max.css`：首页布局。
3. `luci-adapter.css`：LuCI 原生结构与交互状态。
4. 页面专用 CSS。
5. `density.css`：最终尺寸契约，覆盖原生 LuCI 和组件库 `ui-*` 控件。

新增控件使用 `--control-height`、`--control-padding-y/x`、`--form-row-padding`、`--section-padding`，不再单独写 44px 或 48px 的通用设置控件。新增页面仍使用 LuCI 的表单校验、保存、应用和回滚机制。

## 颜色、字体与状态

浅色为灰蓝页面和白色卡片，深色为 #111111 页面、#1c1c1c 卡片、#171717 侧栏。颜色引用语义 token；网络、信号、设备、系统图标依次使用少量蓝、青、紫、金色。

正文与输入 14px，说明 12px，分组标题 16–18px，设置页和弹窗标题 20px，首页标题 32px。正文行高 1.5，字段 20px，说明 18px；数值使用等宽数字。浏览器缩放保留。

刷新使用 18px SVG 线性图标，禁止用 Unicode 字符模拟。按钮有标题、键盘 Enter / Space 操作和焦点环。外观选项保留 aria-pressed。

联通图标去除黑色底板，通过浅深色 CSS 适配字标。登录卡片使用半透明渐变、28px 背景模糊、轻边框与内侧高光；不支持背景模糊时退回不透明底色。

## 响应式

- ≥1280px 首页概览与辅助卡片双栏；701–1279px 辅助卡片两列；≤700px 单列。
- ≤1100px 菜单抽屉；≤700px 底部导航。设置页表格自行横向滚动。
- 触屏使用 40px 控件；不要把桌面的整行大留白复制到手机上。
- 外观偏好通过 `C2000Theme` 保存在当前浏览器，浅色 / 深色 / 跟随系统三种模式。

## 数据与温度

首页使用真实 RPC，数据适配见 [INTEGRATION.md](INTEGRATION.md)。缺失读数显示横线，不填零。CPU / Wi-Fi 默认界面提醒线为 80°C、告警线为 90°C；这是显示规则，不是芯片保护参数，不修改风扇、降频或关机设置。`c2000max_ui` 可覆盖每个传感器的两条线。无效配置显示“阈值无效”，缺失传感器显示“未获取 / 读数不全”。

## 验证

检查浅深色、390 / 811 / 1440px，以及真实 TurboACC、无线、无线编辑弹窗、网络接口、DHCP、QModem、首页和登录。记录控件实际像素与页面/弹窗滚动长度；截图在过渡完成后采集。验证不提交网络配置。


### 手机和平板的表格滚动

横向滚动表格使用 `overflow-x: auto`，仅用 `overscroll-behavior-x: contain` 限制横向滚动传递；纵向必须保持 `overscroll-behavior-y: auto`，让手指在行内容上滑动时能滚动页面。不得对这些表格使用双向 `overscroll-behavior: contain` 或 `none`。独立滚动的模态窗口、导航抽屉按各自边界处理。卡片排序仅允许鼠标从标题发起，触屏内容区域保留浏览器原生滑动、缩放和文本选择。
